# Governance

Savior Systems follows a **lightweight, founder‑led governance model** with clear separation between public‑facing repositories and internal infrastructure.

## Decision‑making
- **Core team** (founders & senior engineers) holds final authority on public‑repo changes.
- **External contributors** propose changes via PRs; core reviewers approve or request revisions.
- **Security‑critical** changes (CI workflows, credential handling) require sign‑off from the security contact listed in `SECURITY.md`.

## Release cadence
- **Monthly** public release schedule for major version bumps.
- **Continuous** integration for all PRs; merges only after successful CI.

## Transparency
All governance documents (`GOVERNANCE.md`, `SECURITY.md`, etc.) live in this repo, making our policy publicly auditable.
