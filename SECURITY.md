## Security Policy

We take security seriously. If you discover a vulnerability in any public repository under the **Savior Systems** organization, please follow these steps:

1. **Do not** disclose the issue publicly (e.g., via public GitHub issues or social media).
2. Email the security contact at `saviorsystembangladesh@gmail.com` with a detailed description of the vulnerability, steps to reproduce, and any relevant proof‑of‑concept code.
3. Allow us reasonable time to investigate and respond before any public disclosure.

**Scope**
- All public repositories owned by the **Savior Systems** organization.

**Out of scope**
- Social engineering, physical attacks, spam, or automated noisy scans.
- Vulnerabilities in private repositories or internal infrastructure.

We do not currently offer a bug bounty program.
