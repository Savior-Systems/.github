# Operating Model

Savior Systems operates as a **founder‑led, AI‑augmented engineering studio**:

- **Core team** (founders + senior engineers) drives architecture, security, and release decisions.  
- **AI agents** (Claude, Antigravity, etc.) generate boilerplate, documentation, and CI scripts.  
- **Continuous Delivery:** Pull‑request‑based workflow with automated testing, static analysis, and secret scanning.  
- **Feedback loop:** GitHub Issues & Discussions are the primary channel for external input.  
- **Governance:** Policies live in the `.github` repo; any change requires a PR and at least one core reviewer approval.
