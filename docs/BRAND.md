# Brand Guidelines – Savior Systems

- **Tone:** Clinical‑grade, minimalist, precise, and quiet luxury.  
- **Colors:** Primary – #0A0A0A (deep charcoal); Accent – #E0E0E0 (soft gray).  
- **Typography:** Inter (400 / 600) for UI, Roboto Mono for code snippets.  
- **Logo usage:** Use the SVG assets in `profile/assets/`. Keep at least 30 px clear space.  
- **Voice:** “We enable developers to build robust, production‑grade solutions with AI‑assisted precision.”

*All public assets should reference the placeholders you’ll replace later; never expose internal branding assets in public repos.*
