# Engineering Principles

1. **Reliability First** – Every public release must pass CI with 100 % test coverage on changed code.  
2. **Minimal Surface Area** – Keep configurations small, defaults sensible, and avoid hidden “magic”.  
3. **Transparent Processes** – All CI steps, secret scans, and release notes are version‑controlled.  
4. **AI‑Assisted** – Use AI agents for boilerplate generation, but all generated code is reviewed by a human.  
5. **Security Hygiene** – No secrets in code; secret‑scan workflow (see `metadata-check.yml`).  
6. **Open Collaboration** – External contributions are welcome but must adhere to the contribution guide.
